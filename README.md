# GLC-UI

Basic setup for the GLC-UI project.

## Tech Stack
- **Framework**: React 19 (Vite)
- **Language**: TypeScript
- **State Management**: Redux Toolkit + RTK Query
- **Styling**: Tailwind CSS v4
- **UI Components**: Shadcn UI (Radix)
- **Routing**: React Router Dom (v7)

## Project Structure
- `src/app`: Core Redux and API configuration.
- `src/pages`: Application pages (lazy-loaded).
- `src/components/ui`: Shadcn UI primitive components.
- `src/components/shared`: Reusable business components.
- `src/assets`: Images, icons, and static assets.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
